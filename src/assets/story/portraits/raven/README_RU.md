# Портрет ворона

В игре используется только один нейтральный портрет:

- `neutral.png` — единственный runtime-ассет ворона.

Любой текст реплики и любое значение `portraitExpression` для ворона намеренно приводятся к `neutral`. Старые экспериментальные `speaking.png` и `surprised.png`, если они остались в рабочей копии после предыдущего патча, больше не импортируются и не используются игрой.
