# Evelyn · layered portrait

Runtime-набор использует:

- `base-neutral.png` — общий полноразмерный базовый портрет;
- `face-smile.png` — небольшой слой лица с мягкой улыбкой;
- `face-speaking.png` — слой лица для обычной речи;
- `face-surprised.png` — слой лица для удивления и тревоги.

Слои лица имеют одинаковую точку привязки и накладываются на базовый портрет.
Переход между выражениями выполняется через прозрачность только изменившегося слоя.

Система поддерживает дополнительные слоты `eyes`, `mouth`, `brows`, `accessory` и `fx`. Для Evelyn первая production-версия использует единый `face`-слой, поскольку он лучше скрывает швы между независимо сгенерированными глазами, ртом и кожей.
