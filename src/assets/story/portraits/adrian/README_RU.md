# Adrian · final layered portrait, scale fix

HOTFIX-059D исправляет две проблемы предыдущей сборки:

1. сменные face-layer были слишком крупными относительно головы;
2. surprised-layer содержал лишние элементы волос и создавал визуальный дубль.

Теперь neutral, smile, speaking и stern уменьшены примерно до 80% от прежнего размера с сохранением центра лица. Surprised заменён на очищенный face-only слой без второй головы и лишней причёски.

Нейтральное состояние по-прежнему собирается из `base + face`, потому что базовый портрет является faceless. Поэтому тест должен ожидать `['base', 'face']`.
