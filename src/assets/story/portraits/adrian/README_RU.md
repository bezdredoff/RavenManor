# Портреты Адриана — full-body v3

HOTFIX-065D заменяет старые face-overlay ассеты на три цельных прозрачных full-body портрета:

- `portrait-neutral-v3.png` — нейтральный / лёгкая улыбка;
- `portrait-speaking-v3.png` — речь;
- `portrait-surprised-v3.png` — удивление.

Все три изображения используют одно и то же тело и костюм. Меняется только голова с выражением лица.

`smile` и `stern` пока безопасно используют нейтральный full-body портрет.
Старые `face-*.png` больше не импортируются в `storyPortraitPresentation.ts`.
