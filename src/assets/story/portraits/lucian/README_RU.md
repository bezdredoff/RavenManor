# Портреты Люциана

Финальные цельные PNG-портреты с прозрачным фоном.

Файлы:
- `portrait-neutral-v2.png` — нейтральное / холодное выражение.
- `portrait-speaking-v2.png` — речь.
- `portrait-surprised-v2.png` — удивление.

`smile` и `stern` пока безопасно используют нейтральный портрет. При расширении набора эмоций можно добавить отдельные файлы без изменения API `storyPortraitPresentation.ts`.
