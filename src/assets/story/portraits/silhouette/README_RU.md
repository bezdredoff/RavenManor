# Портрет неизвестного силуэта

FEATURE-067 заменяет старый `silhouette.svg` на один цельный прозрачный PNG:

- `portrait-neutral-v1.png` — нейтральный full/three-quarter-body силуэт;
- размер: `1024×1536`;
- формат: RGBA PNG с прозрачным фоном;
- runtime-контракт: `single`, ровно один `base` layer;
- все выражения намеренно используют один и тот же asset.

Лицо, глаза, волосы и другие признаки личности скрыты. Это необходимо, потому
что сюжет использует Silhouette до уровня 29, а портрет Люциана раскрывается
только в сцене после уровня 30.

Старый `src/assets/story/portraits/silhouette.svg` может оставаться в проекте как
неактивное наследие, но не должен импортироваться в runtime.

## Production prompt

Asset создан встроенной image generation моделью по утверждённым портретам
Адриана, Люциана и Ворона как стилевым референсам. Ключевые ограничения:

- semi-realistic gothic shōjo/anime;
- стройная мужская фигура в поздневикторианском плаще;
- полностью скрытое матовой тенью лицо, без глаз и волос;
- near-black, charcoal, muted wine-plum и restrained antique-gold;
- без дыма, оружия, крыльев, маски, текста и окружения;
- чистый cutout, пригодный для mobile dialogue UI.
