# Meta Screen Visuals

FEATURE-070 establishes one composition language for Raven Manor's meta-game
screens without changing the FEATURE-069 control system.

## Home

The saved Hall restoration state is the full visual hero. Brand, chapter and
three compact progress counters float over the image. The command deck remains
separate so buttons never cover the room focal area.

## Manor

Five rooms form one vertical route. Alternating room nodes and a central brass
line communicate spatial progression. Unlocked rooms show their current layered
state. Locked rooms retain only a dark, unreadable silhouette beneath the
authored lock.

## Level Map

One continuation card owns the current objective preview. Each room arc then
uses a compact three-column node grid. Nodes retain level number, difficulty,
stars and direct Play/Locked state, while repeated explanatory copy is removed
from the journey surface.

## Room

The current restoration image follows the top bar immediately. Room description
and the route to levels live in a narrow supporting strip. Restoration tasks
form a vertical timeline below the art. Temporary restoration and unlock copy
appears at the lower edge rather than over the image centre.

## Settings

Settings is a contained-scroll ledger. Audio, Language, Gameplay, Board,
Accessibility, Installation and Playtest remain in their established order but
each group has one heading and one continuous surface. Progress reset moves from
Manor into the separated Playtest danger zone.

## Preserved Contracts

- existing room assets and `roomLayeredPresentation` remain authoritative;
- FEATURE-069 design tokens and control states remain authoritative;
- saves, localization, room progression, Match-3, journal and story are
  unchanged;
- FEATURE-071 owns results/transitions and FEATURE-072 owns gameplay HUD.
